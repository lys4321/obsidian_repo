- Lease 란?
	- k8s 에서 리소스 상태 유지와 주기적 갱신(heartbeat) 정보를 관리하기 위한 API 오브젝트
	- 주로 Node Lease 형태로 사용되며 노드의 생존상태(node heartbeat) 를 추적하는 용도로 사용
		=> Lease는 컨트롤 플레인이 노드가 살아있는지 확인하는 경량 오브젝트
	- 컴포넌트 수준의 리더 선출에도 사용
  - 사용 목적
	- node heartbeat 관리
		- kubelet이 주기적으로 갱신
		- 컨트롤 플레인은 갱신 시간을 보고 노드의 생존여부 파악
	- 클러스터 성능 최적화
		- 기존 node status 보다 가볍고 효율적
		- node 상태 확인에 발생하는 etcd 쓰기 부담이 감소
- 노드 하트비트
	- k8s는 Lease API를 사용해 kubelet 노드의 하트비트를 k8s API 서버에 전달
	- 모든 노드에는 같은 이름을 가진 Lease 오브젝트가 네임스페이스에 kube-node-lease 로 존재
	- kubelet 하트비트는 Lease 오브젝트에 대한 업데이트 요청이며 이 요청을 spec.renewTime 필드를 업데이트 하여 Control Plane가 노드의 가용성을 확인하는 용도로 사용
- 리더 선출
	- k8s에서 특정 시간에 컴포넌트의 인스턴스가 하나만 실행되도록 보장할 때 Lease 오브젝트를 사용하기도 한다.
	- kube-controller-manager, kube-scheduler 에서 사용됨
- API 서버 신원
	- k8s v1.26부터 API 서버(kube-apiserver)는 Lease API 를 사용해 신원을 게시하여서 클라이언트가 API 서버의 인스턴스 수를 파악할 수 있게 됨
	- kube-system 네임스페이스에서 apiserver\<sha256-hash>이름의 Lease 오브젝트를 확인가능
		- SHA256해쉬는 kube-apiserver가 보는 호스트 OS를 기반으로 생성됨
- Lease 매니페스트 내에서 사용되는 속성
	- holderIdentity : Lease를 소요한 객체 이름(노드명)
	- leaseDurationSeconds : Lease 유효 기간
	- acquireTime/renewTime : Lease 획득 및 갱신 시간
