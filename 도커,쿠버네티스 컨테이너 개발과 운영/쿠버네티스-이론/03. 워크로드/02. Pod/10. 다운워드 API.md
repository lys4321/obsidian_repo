- 실행 중인 컨테이너에 Pod 및 컨테이너 필드를 노출하는 방법을 의미
	- 환경변수 사용
	- 특수한 볼륨 타입으로 채워진 파일 사용
- 컨테이너가 자신이나 클러스터에 대한 정보를 클라이언트나 API 서버 없이 알 수 있게 하는 수단
- k8s API 필드 중 일부만 다운워드 API를 통해 접근이 가능
- fieldRef와 환경변수를 통해 얻을 수 있는 Pod 필드 정보
	- metadata.name
	- metadata.namespace
	- metadata.uid
	- metadata.annotation\['키']
	- metadata.label\['키']
	- spec.serviceAccount
	- spec.nodeName
	- status.hostIP
	- status.podIP
	- metadata.labels(fieldRef로만 얻기 가능)
	- metadata.annotations(fieldRef로만 얻기 가능)
- resourceFieldRef를 통해 얻을 수 있는 컨테이너 필드 정보
	- resource : limits.cpu
	- resource : request.cpu
	- resource : limits.memory
	- resource : request.memory
	- resource : limits.hugepages-*
	- resource : requests.hugepages-*
	- resource : limits.ephemeral-storage
	- resource : request.ephemeral-storage
