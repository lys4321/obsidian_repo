도커 데몬 및 도커 환경의 시스템 레벨 자원과 정보를 관리하는 명령어
- docker system df [옵션] 
	- 도커의 호스트 디스크 사용량 출력
	- 옵션
		- --format '{{.(컨텍스트)필드명}}' : 특정 필드만 추출해서 출력
			- 이 옵션을 사용할 시 원본 데이터에 접근하게 되어 만약 특정 필드에 아예 값이 없다면 오류 출력됨
- docker system events
	- 도커 데몬에서 발생하는 활동 스트림을 실시간으로 조회
	- 옵션
		- --since 시간 : 지정한 시간 이후에 생긴 내용을 조회
			- 시간 입력 형식
				- 1s, 1m, 1h, 절대시간
		- --until 시간 : 지정된 시간 이전에 생긴 내용을 조회(현재 ~ 지정시간)
			-  시간 입력 형식
				- 1s, 1m, 1h, 절대시간
		- -f(--filter) : 특정 내용만 필터링 시 사용
			- 예 : 'type=container'
- docker system prune
	- 사용하지 않는 컨테이너, 이미지, 네트워크 삭제
	- 옵션
		- -f(--force) : 'y'로 자동 입력하여 바로 삭제하려할 때 사용
		- -a(--all) : 사용되지 않는 모든 이미지까지 삭제할 때 사용
		- --filter : 조건에 필터링된 리소스만 제거
			- 예 : '필터키=필터값'
		- --volumes : 사용되지 않는 볼륨도 삭제할 때 사용
