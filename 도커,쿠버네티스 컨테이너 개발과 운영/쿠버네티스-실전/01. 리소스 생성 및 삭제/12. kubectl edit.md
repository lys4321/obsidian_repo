- kubectl edit \~~~ \[옵션]
	- \~~~ 종류
		- 리소스타입/이름
		- -f 파일명
- 리소스를 직접 편집 시, 사용하는 명령어로 에디터를 열어준다
- 한 번에 여러 리소스 편집이 가능하지만 변경 사항은 순차적
- 옵션
	- --allow-missing-template-keys
		- 템플릿 필드 누락 시 오류 무시
	- --field-manager
		- 서버사이드 apply 용 필드 소유자 이름
	- -f(--filename)
		- 편집할 파일, 디렉토리를 지정
	- -k(--kustomize)
		- kustomization 디렉토리 처리
	- -o(-output)
		- 출력 형식 지정
	- --output-patch
		- 편집 시, patch 출력
	- --recursive
	- --save-config
		- 편집할 리소스를 애너테이션에 저장
	- --show-managed-fields 
		- managedFields 출력 여부
	- --subresource
		- 하위 리소스 편집
	- --template
		- go-template 편집 시, 템플릿을 지정
	- --validate
		- stric/warn/ignore
	- --window-line-endings
		- 윈도우 스타일 줄바꿈으로 강제 시
