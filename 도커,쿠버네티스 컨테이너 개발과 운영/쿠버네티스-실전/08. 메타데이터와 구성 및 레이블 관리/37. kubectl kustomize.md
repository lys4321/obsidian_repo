- kustomization.yaml 파일을 읽어서 최종 KRM(KubernetesResource Model) 리소스를 생성하는 명령
	- Kustomize 필드를 kubectl 내부에서 실행하는 기능
- kubectl kustomize 디렉토리경로 \[옵션]
	- 디렉토리 경로로는
		- git repository URL을 사용가능하며 URL 뒤에 path?ref=branch/tag 형식으로 특정 디렉토리 지정이 가능
		- 해당 경로에는 kustomization.yaml 파일이 반드시 있어야함
- 옵션의 종류
	- --as-current-user
		- kubectl 실행한 내 UID/GID 를 그래도 사용해 함수(container) 실행
	- --enable-alpha-plugins
		- Kustomize의 알파 단계 플로그인 기능을 활성화
	- --enable-helm
		- Helm chart를 inflator generator 로 사용하는 기능을 허용
		- kustomization 안에서 helm chart를 입력으로 사용하게 함
	- --env
	- --load-restrictor
		- 디폴트값은 LoadRestrictionsRootOnly
			- 디폴트값에서는 kustomization root 밖 파일을 가져오지 못함
		- LoadRestrictionNone으로 설정 시 root 밖 파일을 가져오지만 Kustomization 재사용성이 떨어짐
	- --mount
	- --network
	- --network-name
	- -o
