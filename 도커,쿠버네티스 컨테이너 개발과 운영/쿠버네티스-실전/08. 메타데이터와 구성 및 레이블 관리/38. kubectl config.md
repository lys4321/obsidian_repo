- kubeconfig 파일을 읽고 수정하는 명령들의 집합
- kubeconfig 는 k8s 클러스터에 접속하기 위한 정보를 담는 설정 파일
- kubeconfig 로딩 우선순위
	- --kubeconfig 플래그 존재 시, 병합없이 그 파일만 사용
	- KUBECONFIG 환경변수 존재 시, 환경변수에 적힌 여러 파일 경로를 순서대로 병합하여 하나처럼 사용
- kubectl config 하위명령어
- 하위명령어의 종류
	- current-context
		- 현재 어떤 context가 설정이 되었는지 조회
	- delete-cluster
		- kubeconfig에서 특정 cluster 항목을 삭제
	- delete-context
		- kubeconfig 에서 특정 context 항목을 삭제
	- delete-user
		-  kubeconfig 에서 특정 사용자 삭제
	- get-clusters
		- kubeconfig에  정의된 cluster 목록 조회
	- get-contexts
		- kubeconfig에  정의된 context 목록 조회
	- get-users
		- kubeconfig에  정의된 user 목록 조회
	- rename-context
		- context 이름 변경
	- set
		- kubeconfig 파일 내부의 특정 필드 하나를 직접 지정하여 변경
	- set-cluster
		- cluster 항목을 새로 설정하거나 수정
	- set-context
		- context 항목을 새로 설정하거나 수정
	- set-credentials
		- user 항목 설정
	- unset
		- 특정 필드를 제거
	- use-context
		- current-context를 지정한 context 로 변경
	- view
		- 병합된 kubeconfig 파일을 출력하거나 특정 kubeconfig 파일내용을 그대로 출력
