- k8s 리소스에 annotate(주석 데이터)를 추가/삭제/수정 하는 명령어
- Annotate 특징
	- 키값 구조
	- 값은 레이블보다 더 긴 문자열을 저장 가능
	- JSON, 여러 줄 문자열도 입력이 가능
	- 레이블처럼 스케줄링이나 selector에 쓰이지 않음
		- 내부 시스템/도구용 메타데이터를 저장하는데 사용됨
- taint 처럼 마지막에 '-'를 붙이면 삭제의 의미
- kubectl annotate \~\~~ 키=값 ... \[옵션]
- \~\~~의 종류
	- -f 파일경로
	- 타입명 이름
- 옵션의 종류
	- --all
	- --allow-missing-template-keys
	- --dry-run
	- --field-manager
		- 필드 소유권(field ownership)을 추적할 매니저 이름
		- 디폴트는 kubectl-annotate
	- --field-selector
		- 필드 기반 리소스 필터링
	- -f
	- -k
	- --list
		- 지정한 리소스의 annotate 목록만 표시
	- --local
	- -o
	- --recursive
	- --resource-version
		- 지정한 버전의 리소스만 업데이트 하도록 할 때 버전 입력 시, 옵션
	- --selector
		- 레이블 selector로 필터링
	- --show-managed-fields
		- JSON/YAML 출력 때 managedFields 유지
	- --template
		- Go 템플릿 기반으로 출력 시
