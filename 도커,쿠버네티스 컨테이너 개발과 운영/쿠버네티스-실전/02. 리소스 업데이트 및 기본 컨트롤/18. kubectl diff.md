- 현재 클러스터에 적용되어 있는 리소스의 실제 상태와 JSON/YAML 파일의 상태를 비교하는 명령어
	- 비교기 때문에 실제 적용은 하지 않는다.
- CI/CD용 사전 검증 확인용
- 변경상태는 코드로 구분
	- 0(변경 없)
	- 1(변경 유)
- kubectl diff -f 파일명 \[옵션]
- 옵션
	- --concurrency
		- 여러 리소스 병렬로 diff 시, 병렬할 개수
	- --field-manager
		- SSA(Server-Side Apply)에서 소유권 기록 시, 사용하는 매니저 이름
	- -f 
	- --force-conflicts
		- true 지정 시, 서버사이드 적용 시 충돌이나도 강제로 diff
		- 실제 적용은 아님
	- -k
	- --prune
		- 적용 시, 삭제됨 리소스도 diff에 포함
	- --prune-allowlist
		- prune 기능 사용시, 삭제 가능한 리로스종류(GVK)제란
	- --recursive
	- --selector
	- --server-side
	- --show-managed-field
		- k8s managedFields를 diff에 포함할지
