- k8s 리소스의 일부 필드만 수정하는 명령어
- kubectl patch \~\~~ [옵션]
- \~\~~의 종류
	- -f 파일명
	- 타입명 이름
- 패치의 종류
	- strategic merge patch(기본)
	- merge patch
	- JSON patch
- 옵션의 종류
	- --allow-missing-template-keys
	- --dry-run
	- --field-manager
		- 서버사이드 필드오너쉽을 기록 시, 사용
	- -f
	- -k
	- --local
		- 서버 리소스가 아닌 파일내용에서만 패치 적용
		- 실제 API에는 적용하지 않음
	- -o
	- -p(--patch)
		- 패치 내용을 인라인으로 직접 입력 시 사용
	- --recursive
	- --subresource
		- status, scale같은 서브리소스를 대상으로 패치 시 사용
	- --type
		- 패치의 종류를 설정
		- 종류
			- strategic(기본)
			- merge
			- json
