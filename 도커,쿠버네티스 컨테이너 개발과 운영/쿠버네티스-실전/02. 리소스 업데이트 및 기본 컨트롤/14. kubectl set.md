- kubectl set 하위커맨드
- 애플리케이션 리소스 수정을 위한 전용 명령어
- 주로 Pod 을 자동 생성하는 리소스에 사용
- 하위 커맨드 종류
	- env \[옵션]
		- Pod template의 환경변수 수정
		- 옵션
			- -f
			- --selector
			- --all
			- --containers
				- 특정 컨테이너 지정 시
			- --env
				- 추가/변경할 환경변수
			- --from
				- configmap/secret등에서 환경변수 가져오기
			- --dry-run
				- 실제 적용을 하지 않고 변경 내용 미리보기
			- --record
				- 변경사항을 애너테이션에 저장
	- image 리소스명 \[옵션]
		- Pod template의 이미지 수정
		- 옵션
			- -f
			- --selector
			- --all
			- --containers
			- --dry-run
			- --record
	- resources \[옵션]
		- Pod template 리소스 요청/제한 수정
		- 옵션
			- -f
			- --selector
			- --all
			- --containers
			- --dry-run
			- --record
			- --requests
				- cpu나 메모리 요청 설정
			- --limits
				- cpu나 메모리 제한 설정
	- selector \[옵션]
		- 리소스의 셀렉터 수정
		- 옵션
			- -f
			- --selector
			- --all
			- --dry-run
			- --record
	- serviceaccount \[옵션]
		- 리소스의 service account 수정
		- 옵션
			- --selector
			- --all
			- --containers
			- --dry-run
			- --record
			- --serviceaccount
				- 지정할 ServiceAccount 이름
	- subject \[옵션]
		- roleBinding/ClusterRoleBinding에서 사용자, 그룹, service 수정
		- 옵션
			- -f
			- --selector
			- --all
			- --dry-run
			- --user
				- RoleBinding에 추가/변경할 사용자
			- --group
				- RoleBinding에 추가/변경할 그룹
			- --serviceaccount
				- RoleBinding에 추가/변경할 ServiceAccount
