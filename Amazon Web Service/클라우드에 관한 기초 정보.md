- 클라우드 란?
	- 네트워크를 통해 접근할 수 있는 가상화된 서버와 가상화된 서버에서 작동하는 프로그램 및 DB를 제공하는 IT 환경
- 클라우드 컴퓨팅 이란?
	- 클라우드를 이용하여 컴퓨팅 자원을 사용하는 기술적인 방법
	- 서버, 스토리지, 네트워크 등의 자원을 가상화하여 사용자에게 제공함과 동시에 스케일링을 할 수 있도록 한다.
	- 종류
		- Public Cloud
			- 인터넷을 통해 누구나 접근 가능한 클라우드 서비스
			- 클라우드 공급자가 제공하는 인프라를 공유하는 방식
		- Private Cloud
			- 기업이나 조직 내에서 구축한 클라우드 서비스
			- 내부망을 통해 접속하며, 기업이 직접 인프라를 구축하고 운영
			- 내부망을 통해 접속이 가능하도록 되어있어 높은 보안성을 가지며, 특정 요구사항에 맞춤화된 서비스 이용이 가능
		- Hybrid Cloud
			- Public Cloud + Private Cloud 를 결합한 클라우드 서비스
		- Multi Cloud
			- 둘 이상의 클라우드 서비스 제공 업체에서 제공하는 클라우드 서비스를 하나의 애플리케이션 또는 비즈니스에 통합하여 사용하는 방식
- 클라우드 서비스 란?
	- 클라우드 컴퓨팅을 기반으로 제공되는 서비스 
	- 종류
		- SaaS(Software as a Service)
			- 소프트웨어 기반의 서비스
			- 사용자가 애플리케이션을 사용하기 위해 구매/설치하는 대신, 인터넷을 통해 원하는 SW를 사용하도록 제공해 주는 서비스
		- PaaS(Platform as a Service)
			- 플랫폼 기반 서비스
			- 애플리케이션을 개발, 실행, 관리하기 위한 플랫폼을 제공하는 서비스
		- IaaS(Infratructure as a Service)
			- 인프라 기반 서비스
			- 서버, 스토리지, 네트워크 같은 컴퓨팅 리소스 즉, IT 인프라를 제공하는 서비스
- 클라우드 사업자 란?
	- 클라우드 서비스를 제공하는 사업자를 의미
	- 종류
		- CSP(Cloud Service Provider)
			- 클라우드 인프라와 플랫폼, SW, 애플리케이션 등을 제공하는 역할
		- MSP(Managed Service Provider)
			- 기업이나 조직의 클라우드 서비스 운영을 지원하는 서비스를 제공하는 클라우드 회사
- 클라우드의 장점
	- 자원의 스케일링이 유연
	- 분산 운영 구조를 가져 가용성 및 신뢰성이 보장
	- 초기 인프라 구축 비용이 낮음

-  IAM(사용자, 권한, 정책)(Identity and Access Management) 란?
	- 조직의 디지털 리소스(데이터, 애플리케이션 등)에 누가, 언제, 어떻게 접근할 수 있는지 관리하는 시스템
	- 장점
		- 보안 사고 예방
		- 효울성 증대
		- 유연한 접근 제어
	- AWS IAM 
		- AWS 클라우드 환경에서 사용자, 그룹, 역할 등을 생성하고 AWS 리소스에 대하 권한을 관리하는 서비스
	- Google Cloud IAM
		- Google Cloud 리소스에 대한 세부적인 접근 권한을 제어하는 서비스
