- AWS는 모든 데이터 부석 요구사항에 맞는 포괄적인 분석 서비스 셋을 제공
- 분석 서비스 종류
	- Amazon Athena
		- 표준 SQL을 사용해 Amazon S3에 저장된 데이터를 간편히 분석할 수 있는 대화식 쿼리 서비스
		- 서버리스 서비스이기 때문에 관리할 인프라가 없고 실행한 쿼리에 대해서만 비용을 지불
		- Glue Catalog를 자동으로 사용(out-of-the-box : 아무 설정 없이 바로 라는 의미) 하며 Glue에는 크롤러 기능이 있어 스키마를 사용자가 지정하지 않아도 자동으로 만들어 줌
	- Amazon CloudSearch
		- 웹사이트나 애플리케이션에 대한 검색 솔루션을 간단하고 비용 효율적으로 설정/관리 및 확장할 수 있는 AWS 클라우드의 관리형 서비스
	- Amazon DataZone
		- 개인화된 웹 애플리케이션을 통해 데이터를 게시하고 비즈니스 데이터 카탈로그에서 사용할 수 있도록 하는 데이터 관리 서비스
		- SaaS 애플리케이션에서 저장된 위치에 관계없이 데이터에 안전히 액세스가 가능
	- Amazon EMR
		- 오픈소스 도구를 사용해 방대한 양의 데이터를 처리하기 위한 클라우드 빅 데이터 플랫폼
		- 프로비저닝 용량 및 클러스터 튜닝 같은 시간이 걸리는 작업을 자동화하여 빅 데이터 환경을 쉽게 설점/확장 가능
	- Amazon FinSpace
		- 금융 서비스 산업(FSI)를 위해 구축된 데이터 관리 및 분석 서비스
	- Amazon Kinesis
		- 실시간 스트리밍 데이터를 수집, 처리, 분석할 수 있어 신속히 대응이 가능
		- 모든 데이터가 올 때까지 기다렸다가 분석하는 것이 아닌, 도착하면 바로 데이터를 처리하고 분석해 즉시 응답한다.
	- Amazon Data Firehose
		- 스트리밍 데이터를 데이터스토어 및 분석 도구에 안정적으로 로드해주는 방법
		- 데이터 처리량에 맞게 자동으로 확장되며 지속적인 관리가 필요하지 않은 완전 관리형 서비스
		- 데이터 로드 전, 일괄처리, 압축, 변환 및 암호화하여 보안을 강화
	- Amazon Manage Service for Apache Flink
		- 스트리밍 데이터를 분석하고 실행가능한 인사이트를 얻어 비즈니스 및 고객 요구에 실시간으로 대응하는 가능 쉬운 방법
		- 스트리밍 애플리케이션을 빌드, 관리하며 다른 AWS 서비스와 통합하는 복잡성을 줄임
		- 쿼리를 지속적으로 실행하는데 필요한 모든걸 처리하며 수신 데이터의 볼륨 및 처리량 비율에 맞게 자동으로 확장됨
	- Amazon Kinesis Data Streams
		- 웹사이트 클릭 스트림, DB  이벤트 스트림, 금융 거래, 소셜 미디어 파드, IT로그, 위치 추적 이벤트 같은 수심만 개의 소스에서 초당 기가바이트의 데이터를 지속적으로 캡처 가능
			=> 실시간 데이터를 분석, 사용하는데 사용
	- Amazon Kinesis Video Streams
		- 비디오에 대한 분석, ML(머신러닝), 재생 및 기타 처리를 AWS를 위해 연결된 디바이스에서 비디오를 스트리밍할 수 있다.
		- 이것은 여러 디바이스에서 스트리밍 비디오 데이터를 수집하는데 필요한 인프라를 자동으로 프로비저닝하고 탄력적으로 확장
		- 스트림에 비디오 데이터를 안정적으로 저장하며 암호화 및 인덱싱 처리 및 easy-to-use APIs를 사용해 데이터에 엑세스할 수 있다.
	- Amazon OpenSearch Service
		- OpenSearch를 쉽게 배포, 보안, 운영 및 확장하여 데이터를 실시간 검색, 분석 및 시각화할 수 있다.
	- Amazon OpenSearch Serverless
		- Amazon OpenSearch Service의 서버리스 옵션
		- 이를 사용해 OpenSearch 클러스터를 구성, 관리 및 확장하지 않아도 워크로드를 실행할 수 있음
	- Amazon Redshift
		- 클라우드 데이터웨어하우스
		- 표준 SQL 및 기존 비즈니스 인텔리전스(BI)를 통해 데이터를 빠르고, 간단하고 비용 효율적으로 분석
	- Amazon Redshift Serverless
		- 데이터웨어하우스 인프라를 관리할 필요 없이 실행, 확장이 가능
	- QuickSight
		- 조직의 모든 사람에게 인사이트를 쉽게 제공할 수 있는 클라우드 기반의 비즈니스 인텔리전스 서비스
		- 브라우저와 모바일을 지원하는 대시보드를 제공
		- 설치할 소프트웨어, 배포할 서버나 인프라 없이 사용자를 확장할 수 있음
	- AWS Clean Rooms
		- 기업과 파트너가 서로의 기본 데이터를 공유하거나 복사하지 않고도 집합 데이터 셋을 보다 쉽고 안전하게 분석하고 협업할 수 있도록 지원
	- AWS Data Exchange
		- 클라우드에서 타사 데이터를 찾고, 구독하고, 사용할 수 있게하는 것
		- 데이터 제품을 구독 시, AWS Data Exchange API를 사용해 데이터를 Amazon S3에 직접 로드한 다음, 다양한 AWS 분석 및 ML 서비스로 분석
	- AWS Data Pipeline
		- 지정된 간격으로 다양한 AWS 컴퓨팅 및 스토리지 서비스와 온프레미스 데이터 소스 간에 데이터를 처리하고 이동하는데 도움이 되는 웹 서비스
		- 내결함성, 반복성 및 가용성이 뛰어난 데이터 처리 워크로드를 쉽게 생성
	- AWS Entity Resolution
		- 사용자 지정 솔루션을 구축하지 않고도 여러 애
		- 사용자 지정 솔루션을 구축하지 않고도 여러 애플리케이션, 채널 및 데이터 스토어에 저장된 관련 레코드를 일치시키고 연결하는데 도움이 되는 서비스
		- 광고 및 마케팅 캠패인, 로열티 프로그램 등의 경험을 개인화 시킬 수 있다.
	- AWS Glue
		- 고객이 분석을 위해 데이터를 쉽게 준비하고 로드할 수 있는 완전 관리형 추출, 변환 및 로드(ETL)서비스
		- AWS Management 콘솔에 저장된 데이터를 여기에 가리키면 AWS가 데이터를 AWS Glue에 검색하고 관련 메타데이터를 저장
		- AWS Glue 데이터 통합 엔진
			- Apache Spark, PySpark 및 Python을 사용해 데이터에 대한 엑세스를 제공
			- AWS Glue for Ray를 추가 시, 오픈소스 통합 컴퓨팅 프레임워크인 Ray를 사용해 워크로드를 추가로 확장 가능
		- AWS Glue Data Quaility
			- Amazon S3 기반 데이터 레이크, 데이터웨어하우스 등의 데이터 리포지토리의 데이터 품질을 측정하고 모니터링
		- AWS Lake Formation
			- 데이터레이크를 쉽게 만드는 자동화 도구
			- 데이터레이크 생성 시, 필요한 복잡한 작업을 자동으로 해줌
			- 데이터의 위치만 알려주면 데이터를 자동으로 가져와 카탈로그를 생성, 데이터를 S3으로 이동시켜 새 데이터레이크를 구성
				- 데이터를 ML 알고리즘으로 정리 및 분류
				- 보안과 권한 관리도 자동화
			- AWS 분석 서비스와 자동으로 연결 됨
		- AWS Managemented Streaming fot Apche Kafka(Amazon MSK)
			- Apache Kafka 를 사용해 스트리밍 데이터를 처리하는 애플리케이션을 쉽게 구축하고 실행하는 완전 분리형 서비스
			- 이를 사용시 Kafka APIs 를 사용해 데이터레이크를 채우고 데이터베이스 간 변경사항을 스트리밍 및 ML, 분석 애플리케이션을 구동가능
