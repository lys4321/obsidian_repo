- AWS 클라우드 인프라를 구동하는 동일한 온디맨드 확장성, 안정성, pay-as-you 요금 및 기계 학습을 갖춘 혁신적인 비즈니스 애플리케이션
- AWS Business Application 서비스 종류
	- AWS AppFabric
		- SaaS 애플리케이션 전반에서 보안 데이터를 집계하여 정규화하는 완전 관리형 서비스
		- 코딩 없이 여러 SaaS 애플리케이션을 빠르게 연결하여 관찰성, 생산성 및 보안을 높일 수 있음
		- 연결될 시, AppFabric은 데이터를 수집해 OCSF를 사용해 정규화
			- OCSF를 사용하면 공통 정책을 설정하고 보안 알림을 표준화하여 여러 애플리케이션에서 사용자 액세스를 관리
	- Amazon Chime
		- 신뢰 가능한 easy-to-use 애플리케이션으로 온라인 회의를 변환하는 통신 서비스
		- 디바이스에서 작동하며 사용 시, 조직 내부 및 외부에서 콘텐츠를 공유
		- Alexa for Business 와 함께 작동
	- Amazon Chime SDK
		- 빌더가 ML로 구동되는 실시간 음성, 비디오 및 메시징을 애플리케이션에 쉽게 추가
	- Amazon Connect
		- 셀프 서비스 옴니채널 클라우드 고객 센터 서비스
	- Amazon Pinpoint
		- 여러 참여 채널을 통해 대상 메시지를 고객에게 전송할 수 있음
		- 모바일, 웹 앱에 통합해 사용량 데이터를 캡처해 고객이 앱과 작용하는 방식에 대한 인사이트를 제공할 수 있음
		- 사용자 지정 대상 세그먼트를 개발하고 푸시 알림 등을 통해 대상 캠페인을 보낼 수 있음
		- 콘솔이나 Amazon PinPoint REST API를 사용해 트랜잭션 메시지를 보낼 수 있음
	- Amazon Simple Email Service(Amazon SES)
		- 개발자가 모든 애플리케이션 내에서 메일을 보낼 수 있는 비용 효율적으고 유연하며 확장 가능한 이메일 서비스
		- 안전하고 전역적이며 대규모로 이메일을 보낼 수 있음
	- Amazon WorkMail
		- 기존 데스크톱 및 모바일 이메일 클라이언트 애플리케이션을 지원하는 관리형 비즈니스 이메일 및 일정 서비스
		- MS Outlook, 기본 IOS 및 안드로이드 이메일 애플리케이션, IMAP 프로토콜을 지원하는 클라이언트 애플리케이션 등 원하는 클라이언트를 사용하거난 웹 브라우저를 통해 액세스 가능
