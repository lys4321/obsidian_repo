- AWS 서비스에 액세스하기 위해 사용하는 수단
- AWS Management 콘솔
	- 간단하고 직관적인 UI를 통해 AWS에 엑세스하고 관리
	- AWS Management 콘솔 애플리케이션을 통해 모바일 환경에서 조회 가능
- AWS CLI
	- AWS를 관리하기 위한 통합 도구
	- AWS 서비스를 CLI에서 제어하고 스크립트를 통해 자동화도 가능
	- AWS CloudShell라는 브라우저 기반 셸을 통해 AWS 명령과 스크립트를 실행 가능
- Software Development Kits(SDKs)
	- 애플리케이션 프로그램 인터페이스(API)를 통해 애플리케이션에서 AWS 서비스를 간편하게 사용 가능
