- 마이크로서비스(MS), 분산 시스템 및 서버리스 애플리케이션 내에서 분리된 구성 요소 간 통신을 지원하는 서비스 제품군
- 애플리케이션 통합 서비스 종류
	- AWS Step Functions
		- 시각적 워크플로를 사용하여 분산 애플리케이션 및 마이크로 서비스의 구성 요소를 쉽게 조정하는 완전 관리형 서비스
		- 이는 애플리케이션의 구성요소를 일련의 단계로 정렬하고 시각화하는 그래픽 콘솔을 제공(단계적으로 빌드, 실행 가능)
		- 각 단계를 자동으로 시작, 재시작 및 상태 기록을 함
	- Amazon AppFlow
		- SaaS 애플리케이션과 Amazon S3, Amazon Redshift같은 AWS 서비스 간 데이터 전송을 클릭만으로 설정할 수 있게하는 완전 관리형 통합 서비스
		- 이것은 이동 중인 데이터를 자동으로 암호화하고 사용자가 통합된 SaaS의 퍼블릭 인터넷을 통한 데이터 흐름을 제한해 보안을 강화
	- AWS B2B Data Interchange(B2Bi)
		- 전자 데이터 교환(EDI) 문서를 JSON 및 XML 형식으로 자동 변환하여 다운스트림 데이터 통합을 간소화 함
		- 이를 통해 기업은 거래 파트너와 거래 데이터를 교환
		- B2Bi를 사용하면 거애 파트너를 온보딩 및 관리하며 로유 코드 인터페이스를 사용해 EDI 문서를 일반적인 데이터 표현으로 변환하는 작업을 자동화 함
	- Amazon EventBridge
		- SaaS 애플리케이션 및 AWS 서비스에서 생성된 이벤트를 사용해 대규모로 이벤트 기반 애플리케이션을  구축할 수 있도록 하는 서버리스 이벤트 버스
		- SaaS 애플리케이션을 대상으로 실시간 데이터 스트림을 제공
	- Amazon Managed Workflows for Apache Airflow(MWAA)
		- 대규모 클라우드에서 end-to-end 데이터 파이프라인을 더 쉽게 설정하고 운영할 수 있는 Apache Airfolow 대상 관리형 오케스트레이션 서비스
	- Amazon MQ
		- 클라우드에서 메시지 브로커를 쉽게 설정하고 운영할 수 있는 관리형 메시지 브로커 서비스
	- Amazon Simple Notifcation Service(Amazon SNS)
		- 완전 관리형 pub/sub 메시징 서비스
		- 대량의 푸시 기반 메시징에 대한 주제를 제공
		- 이를 사용해 다수의 구독자 엔드포인트에 메시지를 팬아웃을 할 수 있으며 SNS 를 사용해 모바일 푸시 및 알림을 팬아웃 할 수 있음
	- Amazon Simple Queue Service(Amazon SQS)
		- 마이크로 서비스, 분산 시스템 및 서버리스 애플리케이션을 분리 및 확장할 수 있는 완전 관리형 메시지 대기열 서비스
		- 제공하는 메시지 대기열 유형
			- 표준 대기열
				- 최대 처리량, 최선의 주문 및 at-least-once 전송을 제공
			- Amazon SQS FIFO
				- 최대 처리량, 최선의 주문 및 at-least-once 전송 제공
				- 메시지가 전송된 순서대로 정확히 한 번 처리되도록 설계
	- Amazon Simple Workflow Service(Amazon SWF)
		- 개발자가 병렬 또는 순차적 단계가 있는 백그라운드 작업을 빌드, 실행, 확장하는데 도움을 줌
