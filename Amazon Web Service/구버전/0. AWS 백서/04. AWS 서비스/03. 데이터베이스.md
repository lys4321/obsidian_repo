- 관계형 데이터베이스
	- Amazon Rds(Amazon Relational Database Service)
		- 관계형 DB를 사용하게 하는 AWS 관리형 서비스
	- Amazon Aurora
		- AWS가 직접 만든 고성능 관계형 DB 엔진
		- AWS 가 내부 스토리지 엔진을 제작하여 AWS 친화적이라 속도가 빠르다
- 비 관계형 데이터베이스
	- Amazon DynamoDB(key-value)
		- 완전 관리현 NoSQL 데이터베이스
		- 구성 요소
			- Partition Key
			- Sort Key
			- Item
				- 레코드를 의미
			- GSI(Global Secondary Index)
		- 대표 기능 3가지
			- DynamoDB Streams
					- 테이블 변경을 실시간으로 Kinesis/Lambda와 연결 가능
			- DynamoDB Accelerator(DAX)
				- 완전관리형 인메모리 캐시
			- Global Tables
				- 글로벌 리전에 쓰기 좋은 분산 DB
				- 전 세계 사용자 대상 서비스에 필수
	- Amazon DocumentDB(document)
		- MongoDB 워크로드를 AWS 에서 완전관리형으로 돌릴 수 있게 만든 문서DB
		- MongoDB와 동일 방식으로 사용할 수 있지만 실제 엔진은 AWS가 새로 설계
		- 구조적 특징
			- 스토리지와 컴퓨팅을 분리
				- Compute 인스턴스(쿼리를 처리)
				- Storage 계층
			- Multi-AZ 복제
			- 백업 자동 지원
	- Amazon ElasticCache(caching)
		- AWS 에서 제공하는 인메모리 캐시 서비스
		- ElasticCache에서 제공하는 엔진 종류
			- Redis
			- Memcached
		- 간략한 흐름
			- API 서버로 요청
			- API 서버가 캐시에 먼저 데이터가 있는지 확인
				- 있으면 캐시에서 바로 응답
				- 없으면 DB에서 조회 후 캐시에 저장한 다음 응답
		- ElasticCache 쓸 때 (캐시서버)
			- 읽기 요청이 많고 DB에 부담이 클 때
			- DB 부하를 줄이고 성능을 높이고 싶을 때
			- 세션 저장이 필요할 때
	- Amazon MemoryDB(in-memory)
		- Redis와 완전 호환되는 인메모리 데이터페이스
		- 캐시가 아닌 데이터베이스
		- 메모리에 저장되어 속도 향상
		- 내구성 제공
			=> 이것은 캐시가 아닌 인메모리 NoSQL DB
		- 내구성의 이유
			- 여러 AZ에 자동 복제
			- 로그를 이용한 노드 재시작
			- 장애 조치 빠름
		- 쓰는 이유
			- 캐시와 데이터베이스르 따로 운영하지 않을 때
			- MSA에서 고성능이 필요할 때
			- 실시간 성을 띄고 내구성을 보장받아야할 데이터일 때
	- Amazon Neptune(Graph)
		- 데이터를 그래프(노드 + 간선) 구조로 저장하고 관계를 중심으로 데이터를 빠르게 탐색/쿼리 하도록 설계된 데이터베이스
		- 지원하는 그래프 모델
			- Property Graph 모델
				- 노드와 관계에 속성을 추가할 수 있음
				- 언어는 Gremlin을 사용
				- 일반적인 그래프 DB 사용
			- RDF(Resource Description Framework)
				- 삼중 구조
				- 언어는 SPARQL 사용
				- 지식 그래프에 사용
		- 주요 활용 사례
			- 추천 시스템
			- 사기 감지
			- 지식 그래프
			- 네트워크 분석
			- 신약 개발
	- Amazon Keyspace(wide-column)
		- Apache Cassandra와 완전 호환되는 서버리스 NoSQL 데이터베이스
	- Amazon Timestream(time-series)
		- 시계열 데이터를 위한 전용 데이터베이스 서비스
			- 시간의 흐름에 따라 쌓이는 데이터를 말함
		- 시간 기반으로 쌓이는 방대한 데이터를 빠르고 자동으로 처리하는 서버리스 시계열 DB
		- 스토리지 계층
			- 메모리 스토어 (빠른 조회)
			- 마그네틱 스토어 (오래된 데이터 저장)
