- 클라우드 컴퓨팅이란?
	- 인터넷을 이용한 클라우드 서비스 플랫폼을 통해 비용을 지불하면 그 만큼의 컴퓨팅 파워, DB, 스토리지, 애플리케이션 및 기타 IT 리소스를 주문형으로 제공하는 것
	- 클라우트 컴퓨팅은 비용을 지불한 사용자를 위해 이 서비스에 액세스할 수 있는 간단한 방법을 제공
- 클라우드 컴퓨팅의 장점
	- 낮은 초기 비용
		- 처음부터 데이터센터와 서버를 구축을 위한 자금 및 시간적 비용보다 훨씬 저렴한 비용을 지불해 구축 가능
	- 대규모 경제 구조로 인한 이점
		- 다량의 사용자로 인해 지하철을 적은 비용을 사용하는 것 처럼 많은 사용자의 이용으로 인해 양질의 서비스를 받을 수 있다.
	- 용량 추측 불필요(탄력성 관련)
		- 초기부터 용량을 예상하고 설정하는게 아닌, 배포 후 용량을 설정할 수 있기 때문에 예상하는 단게가 필요없다
	- 빠른 IT 리소스 설정 속도(민첩성 관련)
		- 실제 서버는 관리자가 일일해 설정을 해야하지만 클라우딩 컴퓨팅 환경에서는 보다 쉬운 설정법을 제공하여 간단한 동작으로 빠른 설정 결과를 내게 한다. 
	- 데이터센터 운영 및 유지 관리 비용 절감
		- 서버에 관련된 번거로운 작업을 하지 않아도 되어 인프라 관리를 직접 하지 않을 수 있다.
	- 빠른 글로벌 배포 속도
		- 클라우드 서비스가 제공하는 기능으로 인해 쉽게 전 세계 여러 리전(region)에 빠르게 배포가 가능
- 클라우드 컴퓨팅의 유형
	- 많은 사용자가 발생함에 따라 사용자의 특정 요구를 만족하는 몇 가지 다른 모델과 배포 전략이 등장
	- 배포 모델(어디에서 할 건지)
		- 클라우드 
			- 클라우드 기반 애플리케이션은 클라우드에 완전히 배포되며 모든 부분이 클라우드에서 실행
			- 클라우드 기반 애플리케이션은 낮은 수준의 인프라를 기반으로 구축되거나 상위 수준의 서비스를 사용할 수 있다.
		- 프라이빗 클라우드(온프레미스)
			- 가상화 및 리소스 관리도구를 사용하여 온프레미스 리소스(여기선 아마 VM)를 배포하는 것을 프라이빗 클라우드라고 함
			- 이 배포 방법은 클라우드 컴퓨팅의 많은 이점을 제공하진 않지만 전용 리소스 제공하는 능력이 필요하면 떄떄로 요구됨
			- 레거시 IT인프라와 동일하지만 여기에 애플리케이션 관리 및 가상화 기술을 사용해 활용도를 높임
		- 하이브리드
			- 클라우드 기반 리소스와 클라우드에 없는 기존 리소스 같 인프라와 애플리케이션을 연경하는 방법
			- 하이브리드 배포 방법
				- 클라우드 리소스를 내부 시스템에 연결하여 조직의 인프라를 클라우드로 확정하는 방법
				- 클라우드와 기존 온프레미스 인프라 사이를 연결하는 방법
	- 서비스 모델(무엇을 할 지)
		- IaaS(Infrastructure as a Service)
			- 서비스형 인프라
			- 클라우드 IT를 위한 기본 빌딩 블록 포함
			- 네트워킹 기능, 컴퓨터 및 데이터 스토리지 공간에 대한 엑세스
			- IT 리소스에 대한 최고 수준의 유연성과 관리 제어 긴으 제공(=> 개발자 친화)
		- PaaS(Platform as a Service)
			- 서비스형 플랫폼
			- 기본 인프라 관리 필요 없이 애플리케이션 배포와 관리에 집중에 용이
			- 인프라와 관련된 비용, 관리 같은 번거로운 작업에 대한 부담없이 운영하기에 용이
		- SaaS(Service as a Service)
			- 서비스형 소프트웨어
			- 서비스 공급자에 의해 실행되고 관리되는 완전한 제품을 제공
			- 웹 기반 이메일과 같은 최종 사용자 애플리케이션 등을 의미(=> 완제품)
	- (+추가)기타 서비스 모델(XaaS)
		- CaaS
			- Container as a Service
			- 컨테이너 관리 및 배포 환경을 제공
			- 애플리케이션을 컨테이너화 하고 k8s 등을 사용해 컨테이너를 효율적으로 관리
			- IaaS가 VM이나 OS수준의 인프라를 관리한다면 CaaS는 컨테이너 런타임 환경을 제공
		- FaaS
			- Function as a Service
			- Serverless Computing 이라고도 함
			- 서버 관리는 신경쓰지 않고 코드조각(함수)만 업로드 시, 이벤트 발생 시, 자동으로 실행되고 비용이 청구되는 환경을 제공
			- 예시로는 AWS Lambda, Google Cloud Fuctions 등
		- DaaS
			- Desktop as a Service
			- 클라우드에서 호스팅되는 가상 데스크톱 환경을 제공
			- 인터넷만 연결되면 어떤 기기에서는 자신의 데스크톱에 접근할 수 있게 하는 것
		- DBaaS
			- Database as a Service
			- 클라우드 기반의 데이터베이스 관리 시스템을 제공
			- 예시로는 Amazon RDS, Google Cloud SQL등
		- DRaaS
			- Disaster as a Service
			- 재해 발생 시, IT 시스템을 복구하기 위한 백업 및 복구 서비스를 클라우드로 제공하는 것
