- AWS 보안의 이점
	- 데이터 보호
		- 안전한 AWS 데이터센터에 저장됨
	- 규정 준수 및 요구 사항 충족
		- AWS는 인프라에서 수십 개의 규정 준수 프로그램을 관리하며, 규정 준수의 세그먼트가 완료됨을 의미
	- 비용 절감
	- 빠른 확장 
		- AWS 클라우드 사용량에 따라 보안이 확장됨
- 공유 책임 모델(Shared Responsibility Model)
	- AWS는 클라우드 인프라의 보안을 책임지고, 사용자는 클라우드 내의 데이터와 워크로드 보안(구성, 접근 제어)를 책임지는 것
	- AWS의 책임 부분
		- 데이터센터의 물리 보안
		- 서버, 네트워크, 스토리지 같은 인프라
		- 하드웨어 및 소프트웨어 패치
		- 가용성, 내구성 보장
	- 사용자의 책임 부분
		- IAM 계정/권한 설정
		- 네트워크 보안 그룹 VPC 설정
		- S3 버킷 퍼블릭 접근 차단
		- 암호화 적용 여부
		- 애플리케이션 레벨 보안
		- 
- AWS가 제공하는 주요 보안 서비스
	- IAM(Identity and Access Management)
		- 사용자 권한/접근 제어
	- KMS(Key Management Service)
		- 데이터 암호화 키를 관리하는 서비스
	- Security Group / NACL
		- 네트워크 방화벽 역할
	- AWS WAF(Web Application Firewall)
		- 웹 공격(SQL Injection, XSS 등) 차단
	- Shield
		- DDoS 방어 서비스
	- CloudTrail
		- 누가 무얼 했는지 기록하는 감사 로그
	- GuardDuty
		- AI 기반 위협 탐지
	- Config
		- 리소스 설정 변경을 추적하고 규칙 위반 감지
