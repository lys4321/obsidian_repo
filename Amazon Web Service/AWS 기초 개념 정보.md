- AWS 글로벌 인프라 개념
	- Region
		- AWS가 전 세계에서 데이터센터를 클러스터링하는 물리적 위치
		- 논리적 데이터센터의 각 그룹을 가용영역(AZ)라고 함
		- 각 리전은 지리적 영역 내에서 격리되며, 격리된 것 하나당 물리적으로 분리된 최소 3개의 AZ로 구성
	- AZ(Availability Zone)
		- AWS 리전 내 에서 중복 전력, 네트워킹 및 연결이 제공되는 하나 이상의 개별 데이터센터 들의 묶음
		- AZ 사용 시, 높은 가용성, 내결함성 및 확장성 보장
		- 리전 내 AZ 간 연결은 전용 광 네트워크와 연결되어 높은 처리량과 지연 시간이 짧은 네트워킹을 제공
		- 모든 AZ는 100Km 이내 거리에 위치

- 계정 구조(Account Structure)
	- AWS 에서 계정 이란?
		- 기본 단위
		- 모든 리소스는 반드시 특정 계정 소속으로 존재
	- Root User
		- AWS 계정을 처음 생성하면 만들어지는 최상위 권한 사용자
		- 모든 권한을 보유
		- MFA 가 필수적
		- 필요할 때만 사용하고 평소에는 보관하는 것이 원칙
	- IAM User / Group
		- AWS를 실제 운영하는데 사용하는 일반 사용자
		- 팀원 별 계정 부여가 가능
		- Policy로 세밀한 권한 제어가 가능
		- 그룹일 경우 유사한 역할을 가진 사용자들을 묶는 단위를 의미
	- IAM Role
		- 사람이 아닌, 서비스나 애플리케이션 및 AWS에 권한을 부여하기 위한 구조
		- EC2에서 S3 접근이나 Lambda에서 DynamoDB로 접근 같은 서비스 간 권한 연결을 하기위해 역할을 사용
	- Organizations
		- 여러 개의 게정을 묶어서 관리하는 것
		- 걔정 구조라는 개념이 확장 됨
		- 구성요소
			- Management Account
				- 조직을 관리하는 매인 계정
			- Member Accounts
				- 실제로 서비스를 운영하는 하위 계정들
			- OU(Organization Unit)
				- 계정들을 묶는 그룹
			- SCP(Service Control Policies)
				- 조직 단위의 정책을 강제

- EC2(Elastic Compute Cloud)
	- AWS Cloud에서 사용자의 필요에 따라 컴퓨팅 리소스를 제공하고 사용한 만큼 비용을 청구하는 서비스
	- 구성 요소
		- AMI(Amazon Machine Image)
			- OS와 애플리케이션을 실행하기 위한 템플릿, 인스턴스 생성 시 사용되는 설계도
		- 인스턴스
			- AWS Cloud의 가상 컴퓨터
-----
- S3(Simple Storage Service)
	- AWS에서 제공하는 Cloud 기반의 객체 스토리지 서비스
	- Bucket이라는 저장공간에 Object 형태로 저장
		- Object는 파일과 해당 파일을 설명하는 메타데이터로 구성
	- 특징
		- 사이즈가 커질 시, 자동으로 확장되는 내구성
		- 완전 관리형 서비스
		- 암호화 및 보안
			- 버전 관리가 가능
			- 서버 측 암호화인 SSE 제공
			- IAM, 버킷 정책 등으로 세밀한 접근 제어 가능
			- 삭제 방지 기능도 제공(WORM)
		- 수명 주기 기능 지원
			- 오래된 데이터를 점차 저렴한 스토리지 클래스로 자동으로 이동시며 비용을 절감
-----
- Amazon RDS(Relational Database Service)
	- AWS에서 관계형 데이터베이스를 사용 및 설정하게 해주는 관리형 서비스
-----
- Amazon VPC(Virtual Private Cloud)
	- AWS 내에서 사용자가 원하는 형태로 구성하는 가상 네트워크
	- 필요한 이유
		- 보안성이 추가된 네트워크를 구성하기 위해
		- 클라우드 환경에서 내부 네트워크를 직접 구성하기 위해
		- 온프레미스와 AWS를 하나의 네트워크처럼 설정하기 위해
	- VPC에서 설정 가능한 것
		- IP 주소 범위 설정
		- 서브넷 설정
			- Public/Private 서브넷
		- 라우팅 테이블 설정
		- 게이트웨이 설정
			- IGW(Internet Gateway)
			- NAT Gateway
				- 프라이빗 서브넷에서 인터넷 아웃바운드만 허용
			- VGW(VPN Gateway)
				- 온프레미스와 AWS VPN 간 연결 시
			- Transit Gateway
				- 여러 VPC 및 온프레미스 네트워크를 중앙에서 연결
		- 보안 기능 설정
			- Security Group
				- 인스턴스 단위의 방화벽을 설정
				- Stateful
				- 포트포워딩
			- Network ACL(NACL)
				- 서브넷 단위의 방화벽
				- Stateless
				- 서브넷 포트포워딩
